# 首次使用

## 启动

在项目目录运行：

```bash
npm run serve
```

浏览器打开 `http://localhost:8080`，无需账号或登录。

## 建议的第一步

1. 点击“新建任务”，记录当前最需要推进的事项。
2. 为任务选择象限，明确轻重缓急。
3. 在四象限视图中调整顺序。
4. 定期使用导出功能备份本机数据。

## 使用 AI

点击页面顶部或行动台中的“AI 设置”，填写 CSTCloud API Key 和账号支持的模型名称。

接口固定为 `https://uni-api.cstcloud.cn/v1`，API Key 仅加密保存在当前浏览器。

## 数据边界

所有业务数据默认保存在浏览器本地。清理站点数据或更换设备前，请先导出备份。
